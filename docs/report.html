routeflow

Swagger shows the contract.
RouteFlow shows what actually happened.

A decorator, a live node graph, and a tab next to your FastAPI docs — order, timing, logs, and errors for every traced request, instead of piecing it together from scattered logs.

$ pip install routeflow

How it works

1
Decorate what you want traced
@track on any function, sync or async — nesting builds itself from call order.
2
A request comes in
Middleware opens a trace; every @track-ed call along the way becomes a timed, nested span.
3
Open the flow view
A tab next to Swagger — the same request, rendered as an interactive node graph, live.
